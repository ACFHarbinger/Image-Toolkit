**What happened this session** (pivoted here from Build-Optimization
mid-session, first time touching Image-Toolkit today):

1. `just python` failed with `python: command not found`. Root cause:
   the repo was moved from `~/Repositories/Image-Toolkit` to
   `~/Repositories/Repo/Image-Toolkit` at some point, but `.venv`'s
   activate scripts still hardcoded the old path — sourcing `activate`
   prepended a nonexistent directory to `PATH`. Fixed: `rm -rf .venv &&
   uv sync --all-groups --all-packages` (full recreate, not a path
   patch — also self-heals any other absolute-path leakage a sed
   wouldn't catch). Verified: `python --version` → 3.11.14, `PySide6`
   imports clean (6.10.0).
2. Once `just python` actually ran, Harbinger hit
   `module 'base' has no attribute 'database'` opening the unified
   library DB. Two stacked causes, both fixed:
   - The `base` pybind11 C++ extension had never been built. Because
     `base/` (C++ source, no `__init__.py`) sits on `sys.path` via cwd,
     `import base` was silently resolving to an empty PEP 420 namespace
     package instead of raising `ImportError` — a genuinely confusing
     failure mode worth remembering (`base.__file__` is `None` for the
     namespace-package shadow, a real `.so` path for the actual
     extension — check that first next time something `base`-adjacent
     looks like a missing-attribute bug). Fixed: `pixi install` (pulls
     the pinned OpenCV 4.13/Eigen3 conda packages) + `just build-base`.
   - Built extension still refused to construct `Database(...)`:
     `"base was built without SQLCipher/libsodium."` `HAVE_SQLCIPHER`
     gates the whole encrypted-DB layer on **both** being found at
     CMake-configure time — libsodium was available (pixi env),
     SQLCipher wasn't installed on the system at all. Asked Harbinger
     before doing anything sudo/system-wide (correctly didn't just run
     it); **Harbinger installed `libsqlcipher-dev` himself**. Rebuilt
     `base` — `flags.make` now shows `-DHAVE_SQLCIPHER=1`, and a live
     smoke test (`base.database.Database(tmp, pw, salt)`) constructed
     and closed successfully.
