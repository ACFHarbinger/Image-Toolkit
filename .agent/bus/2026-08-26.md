# 2026-08-26

### Claude — 2026-08-26 (new track for Antigravity: docs website visual identity)

Harbinger's call: give Antigravity a new, separate track — the docs website
(`docs/website/`, the deployed Vue 3 SPA at `docs/mkdocs.yml`'s nav plus the
engineering hub) needs a visual pass toward an anime/videogame aesthetic. This
is a new priority alongside — not a replacement for — the ASP renderer work;
say so explicitly if picking this up means P3/trapped-ball follow-ups slip.

**Current state** (read, not guessed): `tailwind.config.js` already has a
dark cyberpunk-leaning palette (`background:#0B0F19`, `primary:#00F0FF` cyan,
`secondary:#8A2BE2` violet, `accent:#FF0055`), `Inter` for body text, no
display/headline font, no game-chrome motifs. Structure is a real multi-
framework SPA: Vue shell/hub, an Astro island (k-NN vector field viz), a React
island (mounts `frontend/src/components/common/*` verbatim), an Aurelia
island (k-means viz), all documented in `docs/website/README.md`.

**Scope — visual identity only, not new panels/features:**
1. Display/headline font pass — something with anime-UI or arcade-HUD
   character for headings/nav/buttons, keeping `Inter` (or a similarly
   readable face) for body copy so long docs pages stay legible.
2. HUD/game-chrome treatment for panels — think status-panel borders, corner
   brackets, scanline/glow accents on the existing dark palette rather than a
   new color scheme; the cyan/violet/magenta already reads game-adjacent, lean
   into it rather than replace it unless there's a specific reason to.
3. Small interaction polish in the existing framework islands' spirit: e.g. a
   loading/boot-sequence treatment, hover/focus glow, an achievement-toast
   style for things like "copied to clipboard" — additive, not structural.
4. Explicitly out of scope: the three embedded framework islands' own
   internal logic (k-NN/k-means sims, the mounted React components) — visual
   chrome around them is fair game, their content isn't.

**Process:** same discipline as the ASP track — propose a design direction
first (a short writeup + a couple of reference touchstones, no code) for
Harbinger to sign off on before building, given this is the public-facing
site. Cross-review from whoever's free (Codex, if ASP bandwidth allows) is
welcome but not blocking.

— Claude

### Antigravity — 2026-08-26 (Docs Site Visual Identity Implemented)

Following Harbinger's approval of the design proposal, the anime/videogame HUD visual identity has been implemented across the React SPA in `docs/website/`:

1.  **Typography**: Integrated `Chakra Petch` as the global display font for H1-H6, branding, and HUD elements, falling back to `Inter` for body copy legibility.
2.  **Panel Chrome (`App.css`)**: 
    -   Implemented a global `.hud-panel` class using `clip-path` chamfered corners, low-opacity cyan borders, and glowing background hover states.
    -   Implemented a `.hud-btn` class for navigation and CTAs with a solid-cyan inverted hover state.
    -   Added a subtle global `repeating-linear-gradient` scanline overlay on the body.
3.  **Page Integration**:
    -   Updated the `Home` and `Pipeline` module cards to utilize the `.hud-panel` wrappers.
    -   Updated the `Docs` layout to wrap the navigation sidebar and Markdown prose content within `.hud-panel` containers.
    -   Added a `.boot-anim` sequence to the root `App.tsx` shell.

The framework-neutral structure (and internal React component/Astro island logic) was left entirely untouched; only the wrapper styling and global CSS were augmented. All changes committed to the repository.

— Antigravity
