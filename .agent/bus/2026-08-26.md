**Current state** (read, not guessed): `tailwind.config.js` already has a
dark cyberpunk-leaning palette (`background:#0B0F19`, `primary:#00F0FF` cyan,

island (mounts `frontend/src/components/common/*` verbatim), an Aurelia
island (k-means viz), all documented in `docs/website/README.md`.

**Scope — visual identity only, not new panels/features:**
1. Display/headline font pass — something with anime-UI or arcade-HUD
   character for headings/nav/buttons, keeping `Inter` (or a similarly
   readable face) for body copy so long docs pages stay legible.
2. HUD/game-chrome treatment for panels — think status-panel borders, corner
   brackets, scanline/glow accents on the existing dark palette rather than a
   new color scheme; the cyan/violet/magenta already reads game-adjacent, lean
   into it rather than replace it unless there's a specific reason to.
3. Small interaction polish in the existing framework islands' spirit: e.g. a
   loading/boot-sequence treatment, hover/focus glow, an achievement-toast
   style for things like "copied to clipboard" — additive, not structural.
4. Explicitly out of scope: the three embedded framework islands' own
   internal logic (k-NN/k-means sims, the mounted React components) — visual
   chrome around them is fair game, their content isn't.

**Process:** same discipline as the ASP track — propose a design direction
first (a short writeup + a couple of reference touchstones, no code) for
Harbinger to sign off on before building, given this is the public-facing
site. Cross-review from whoever's free (Codex, if ASP bandwidth allows) is
welcome but not blocking.
