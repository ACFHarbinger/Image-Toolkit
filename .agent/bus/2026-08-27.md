#### 1. Corpus Phase Distribution & P1 Suppression Scope
Across the frozen 97-case benchmark corpus:
- **Multi-phase source sequences**: **59 / 97 cases (60.8%)** have `n_phases > 1` (e.g. `test01`, `05`, `08`, `09`, `11`, `12`, `13`, `15`, `16`, `17`, `18`, `21`, `26`, `27`, `28`, `32`, `33`, `34`, `36`, `38`, `39`, `40`, `41`, `43`, `45`, `46`, `48`, `49`, `51`, `52`, `54`, `55`, `56`, `57`, `58`, `59`, `62`, `63`, `67`, `71`, `72`, `73`, `74`, `75`, `77`, `79`, `80`, `82`, `83`, `84`, `86`, `87`, `88`, `89`, `90`, `91`, `95`, `96`, `97`).
- **Single-phase source sequences**: **38 / 97 cases (39.2%)**.
- **Crucial Architectural Catch in `composite.py:109-114`**:
  When `plate_single_pose_safe_for_phases` rejects a multi-phase sequence, `_composite_foreground` currently does:
  ```python
  if plate_single_pose_enabled() and N >= 2:
      print("[Stitch]   plate_single_pose skipped for multi-phase sequence.")
      if seam_meta_out is not None:
          seam_meta_out["plate_single_pose_skipped"] = "multiple_phases"
      return canvas.copy()
  ```
  Returning `canvas.copy()` immediately **bypasses the legacy seam-carving compositor** (lines 131+), leaving an uncomposited raw temporal median canvas with moving-cel ghosting. In the baseline corpus, **20 of these 59 multi-phase cases** were valid `RAW_ASP` outputs under the legacy seam compositor. If `ASP_PLATE_SINGLE_POSE=1` is turned on with this hard early-return, all 20 will fail downstream visibility/coverage checks and silently regress to `SCANS` fallback!
  *(Fix recommendation: when multi-phase gate skips P1, fall through to the legacy seam loop rather than early-returning `canvas.copy()`)*.

#### 2. Case-17 Roadmap Accounting
- **Verdict**: Case 17 routing to SCANS fallback must be recorded as a **known quality gap / future work candidate** in the ASP roadmap, **not** marked as "resolved".
- **Rationale**: Case 17's baseline was already Safe ASP (SCANS fallback). Bypassing P1 via the phase gate simply returns case 17 to its baseline fallback behavior without solving the underlying computer-vision challenge (multi-phase pose-change animation stitching, which requires piecewise multi-plate synthesis or per-phase hero cel extraction).
