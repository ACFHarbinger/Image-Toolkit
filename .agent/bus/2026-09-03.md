`_internal/assets/secrets/` and `_internal/assets/api/` in *both* the
AppImage and the `.deb` contain:
- `my_keystore-a.p12` (429 B) — **byte-identical** to the maintainer's real

- `my_secure_data-a.vault` (120 KB) — real encrypted vault

(`git ls-files assets/secrets assets/api`), and `ImageToolkit.spec:100`
bundles all of `assets/` with no `secrets/` or `api/` exclusion. The
per-account pepper is correctly *not* bundled, so the vault is not trivially
decryptable from the artifact alone — still a clear NO-GO.
Disposition (Harbinger's call, not actioned here): strip from artifacts +
build + spec, purge/rewrite from git history, rotate every exposed
credential and the account-`a` keystore.

### Claude — 2026-09-04 (release §4: palette bug fixed)

Fixed Finding 5 from the earlier evidence report before continuing §5.
Frozen (PyInstaller) Qt ships no KDE/GTK platform-theme plugin, so
`QApplication.palette()` stayed Qt's built-in *light* default even under
the dark QSS. Widgets that read the palette directly instead of the
stylesheet (`OptionalField` collapsible headers) rendered white-on-dark.

Fix: `_theme.py` now builds an explicit `QPalette` from the same
DARK_*/LIGHT_* vars the QSS uses (`Window`/`Button` → bg, `Base` →
secondary/surface bg, `WindowText`/`ButtonText`/`Text` → text,
`Mid` → border, `Highlight` → accent, disabled group → muted text) and
calls `QApplication.setPalette()` in both `set_application_theme` (dark/
light) and `apply_theme_pack` (#437 ThemePack path, using the pack's
resolved colors). New helper `_build_palette()`.

Verified: `gui/test --run-gui -k "theme or main_window"` → 48 passed;
`test_login_window.py --run-gui` → 13 passed; direct smoke script
confirmed `QApplication.instance().palette()` Window/Base/Text match
DARK_BG/DARK_SECONDARY_BG/DARK_TEXT and the light equivalents after
calling `set_application_theme`. ruff clean (pre-existing blank-line
format nit at line 139 predates this change, untouched).

Not yet re-verified in the frozen onedir build (needs a rebuild + visual
check of `OptionalField` headers) — do that before crossing Finding 5 off
for §4.2 sign-off.

Files touched: `gui/src/windows/main/_theme.py`.
