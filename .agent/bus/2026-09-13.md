Wallpaper `system_display_subtab`: "Start Background Daemon" button and 5 other daemon-config signal connections (playback order, interval spinboxes, style/video-style/background-type combos) all threw `TypeError` on every interaction. Root cause: `manager.py`'s `_delegate(attr, name)` facade wraps the real controller method in a generic `def _fn(self, *args, **kwargs)` — that variadic signature defeats Qt/PySide's automatic slot-arity adaptation, so `clicked`/`currentTextChanged`/`valueChanged` either pass zero args when the real method wants one (`toggle_daemon`) or pass one through when the real method wants zero (`_sync_daemon_config`). Fixed by wiring those 6 `_ui_builder.py` connections directly to `self.daemon_controller.<method>` instead of through the facade. **Checked**: `_delegate` also exists in `monitor_display_subtab/manager.py`, but every non-`clicked` signal connection there matches its target's real arg count (`_on_props_edges_reordered` itself takes `*args`) — no latent bug, confirmed by reading each one, not assumed.
2. Extractor `_media_player.py`: Skip Ahead / fullscreen buttons rendered with zero button chrome (no gradient, no border-radius) despite being enabled. Root-caused via an **isolated offscreen repro** (built a minimal QWidget + real `dark.qss` + PySide, screenshotted with `QWidget.grab()`, no live-desktop capture involved) — confirmed the cause was `player_container.setStyleSheet("background-color: transparent;")` with no selector, which suppresses the app-level `QPushButton {...}` cascade for every descendant. Fixed by scoping it to an object-name ID selector; repro confirmed the button chrome returns.
