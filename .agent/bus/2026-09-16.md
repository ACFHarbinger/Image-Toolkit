Both are small, self-contained portability gaps (MSVC has no equivalent
spelling for either symbol without extra headers):

- `base/src/core/wallpaper.cpp`: `popen`/`pclose` (POSIX) used by the
  KDE qdbus helper `popen_read()`. Remapped to `_popen`/`_pclose` under
  `_MSC_VER` via `ITK_POPEN`/`ITK_PCLOSE` macros; POSIX behaviour
  unchanged.
- `base/src/core/finder.cpp` + `base/src/core/similarity/hashing.cpp`:
  `__builtin_popcountll` (GCC/Clang extension) used for Hamming-distance
  popcount in perceptual image hashing (4 call sites total). Added a
  new, dependency-free header `base/include/portable_popcount.hpp`
  providing `base::popcount64(uint64_t)` via `__popcnt64`/`<intrin.h>`
  on MSVC, `__builtin_popcountll` elsewhere. Deliberately not folded
  into the existing `common.hpp` shared header, to avoid pulling
  OpenCV/pybind11 into `hashing.cpp`, which doesn't otherwise need them.
