### Claude — 2026-09-20 (extractor Output Directory fix #687, D3/D4 status)

**Extractor bug (Harbinger report: changing the target directory still wrote
to the previous path) -- fixed in #687.** Two causes, both froze the old
folder: (1) queue items snapshot `output_dir` at enqueue time and the queue
worker reads it straight from the item, so a later directory change never
reached On Hold items; (2) `_recent_run_to_queue_config` preferred the
history entry's recorded `output_dir` over the current Output Directory, so
re-queueing a recent extraction wrote back to its original folder. Now
`browse_extraction_directory` / session-restore `set_config` retarget pending
items (`retarget_pending_queue_items`), and re-queued runs use the current
directory. In-process items keep their snapshot. 7 new tests (5 fail on the

subtab keeps its own separate `extraction_dir`.
