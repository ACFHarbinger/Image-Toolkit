### Mistral — 2026-10-13 (#756 claimed — Hutchinson Hessian trace / Generalization Gauge)

Claiming [#756](https://github.com/ACFHarbinger/Image-Toolkit/issues/756)
per the backlog delegation. Branch `dl-756-hessian-trace` off `main`
per Harbinger's work-on-main direction (feature branch, PR, Codex
review), worktree `~/Downloads/Data/Tests/dl-756`. Contracts:

- `backend/src/models/hooks/hessian_trace.py`: Hutchinson trace via
  5 Rademacher vectors on **adapter parameters only** (requires_grad),
  computed with double-backward HVPs; seeded generator → identical
  vectors every checkpoint (deterministic, comparable across checkpoints).
  `autograd.grad` never touches `.grad`, so training state is preserved
  by construction.
- **Frozen validation batch:** frozen at the FIRST checkpoint from the
  then-current batch (latents/embeds/SDXL micro-conditioning detached
  and cloned) with noise/timesteps drawn once from `validation_seed` —
  the same batch is reused at every later checkpoint, so the trace
  series measures the loss surface evolving under training, not batch
  churn.
- **Hook:** V2's checkpoint branch (`_maybe_hessian_trace`, fail-soft
  like `_maybe_sample_grid`; off-switch `hessian_vectors: 0`). Trace
  lands through `DiagnosticsLogger.log_step` as `hessian/trace` +
  `hessian/param` (per-parameter), so TB/W&B/JSONL all get it and the
  live panel/report card read the same series. Cost is documented: ≈1
  forward + (2+v) backward-equivalents per checkpoint (~4 training steps
  at v=5). `hessian_vectors: 5` declared in base.yaml's `training:`
  (following the `sample_grids` pattern), dataclass field, `_build_tuner`
  passthrough.
- **"Generalization Gauge" surfacing:** no checkpoint-card GUI surface
  exists yet, so v1 surfaces where cards actually read from — a fourth
  report-card verdict ("Sharp or flat?") driven by the hessian/trace
  trend from events.jsonl (rising = sharp/brittle = overfitting risk;
  falling/low = flat), plus the raw metric in events for any future
  card/filmstrip. Deviation from the issue's "checkpoint cards" wording
  flagged for Codex's review.
- Exact-math tests: diagonal Hessians make the Hutchinson estimate
  variance-free (z²=1), so traces are asserted exactly; cross-term HVP
  math verified by replicating the seeded vectors in the test. Changelog
  entry in docs/CHANGELOG.md per the delegation.

Targeted tests only; no suite/GPU/benchmark.
