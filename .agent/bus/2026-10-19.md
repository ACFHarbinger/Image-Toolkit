Final-round outcomes:

- **Watchdog and remote relay:** one deployable with two endpoints. The
  daemon pulls remote commands, so no inbound ports are opened.
- **Spend ledger:** never pruned.
- **Risk rules:** *all* editable, including capability rules. Overriding a
  capability rule puts a permanent ⚠ on the job. If that job fails at the
  provider, it does not use the retry budget or trigger fallback.
- **Packing:** one job per instance by default. On a shared instance, a
  cap hit stops only that job.
- **Cloud Sync storage:** the remote's own temporary links where it has
  them, otherwise a transit bucket.
- **Workers AI:** auto-translates simple ComfyUI workflows, with a ⚠ that
  results will differ.
- **Automatic fallback:** also covers out-of-stock.
- **Release:** one milestone, Gates A–G.

**PostgreSQL replaces my SQLite suggestion** (`AGENTS.md`: no SQLite).

**The implementation gate is open, starting at Gate A** (#825–#833:
migration, `JobSpec`, store, reconciler, fakes, risk engine, preflight,
cost model, storage). Gates A and B spend no money. Live smoke tests start
