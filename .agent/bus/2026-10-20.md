### Gemini — 2026-10-20 (#879 W0-15: Vault in C++ core & sealed leases ready for review)

Implemented #879 (Wave 0e W0-15):
1. **Vault in C++ core (`backend.vault`):**
   - Keystore (`unlock`) and direct Argon2id (`unlock_direct`) unlock held strictly in C++ memory via `LockedSecret<32>` (`mlock` + `sodium_memzero`).
   - Returns opaque session handle `vses_<hex>` for the webview/sidecar. Plaintext DEK never enters Python, Rust, IPC, or webview.
   - Session lifecycle: `is_unlocked`, `lock`, `lock_all`, `active_sessions`.
2. **Sealed per-store leases (`itkl_v1_...`):**
   - Cryptographic AEAD tokens (`crypto_aead_xchacha20poly1305_ietf`) sealing derived store-specific DEKs (e.g. `cloud_jobs` subkey derivation via BLAKE2b keyed hash).
   - Enforces store identity, TTL expiry timestamps, caller PID binding (`getpid()`), and optional supervisor session binding.
   - Inspection utility `verify_store_lease` returns metadata dictionary (`store_name`, `expires_at`, `bound_pid`, `is_expired`, `valid`) without exposing key material.
3. **Database connection integration (`backend.database.Database`):**
   - Direct factory: `Database.from_lease(path, lease_token, expected_store="")` and constructor overload `Database(path, lease_token)`.
   - In-process session factory: `Database.from_session(path, session_handle, store_name="library")` and constructor overload `Database(path, session_handle, store_name)`.
   - Backward-compatible with 3-arg `Database(path, password, salt)`.
4. **Middleware store support:**
   - `open_store_db` in `middleware/src/cloud/store/db.py` accepts `lease: Optional[str] = None` while preserving legacy `(secret, salt)` signature.
   - `VaultManager` in `middleware/src/core/vault_manager.py` exposes `get_session_handle()` and `create_store_lease(store_name, pid, ttl_seconds, supervisor_session)`.
5. **Testing & Verification:**
   - Added comprehensive targeted unit test suite: `middleware/test/database/test_vault_sealed_leases.py` (14/14 passed in 2.76s).
   - Existing suites (`test_base_database.py`, `test_vault_manager.py`, `test_cloud_jobs_storage.py`) verified green (35/35 passed).
   - Built and installed extension via `just build::build-base` with `$ORIGIN` runtime path. No full suites or benchmarks run.
