# Convert pilot #894

This branch is the capability PR. It contains the contract (`convert.convert`, `convert.convert_batch`), regenerated bindings, the sidecar handlers registered on `SidecarServer`, `HostClient.convert` / `convertBatch`, removal of the `convert_image_batch` stub, and `bridge_request` so the shell can keep one sidecar process.

`Shell` constructs a `HostClient` over `RustTransport`, connects it on mount, closes it on unmount, and passes that instance into `CatalogView`. `ConvertPilot` calls `hostClient.convert` with `output_format` taken from the output suffix (or the format selector when the path has none).

`bridge_request` resolves the sidecar from the packaged `sidecar-runtime` resource, `IMAGE_TOOLKIT_RUNTIME`, or a checkout found from the running executable. A dead child fails its waiters and the next request starts a new process and handshake. `convert.convert_batch` queues a job, emits progress, and checks cancellation between files so the stdio reader stays available.

`middleware/src/services/convert/` is the existing Qt-path service. The handler maps the bridge params onto `ConvertSingleCommand` / `BatchConvertCommand` and does not add a second converter. Quality stays the canonical value 95.
