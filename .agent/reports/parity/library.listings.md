# library.listings

Qt listings are series cards and entity cards (MAL-oriented media tracking). The live store methods used by the sidecar are groups, subgroups, tags, and image metadata. This page edits those records (rename, category, image group/subgroup/tags, delete) when a session store is attached.

PARITY-GAP library.listings: series listings, entity listings, and MAL sync are not implemented. The schema has `media_items` and `entities`, but there is no MAL client and no series/entity editor on this bridge.
