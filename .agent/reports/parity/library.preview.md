# library.preview

Search, listings, and scan call the existing `library_preview.describe` and `library_preview.frame` services for the selected path. The pop-out window is unchanged. Preview does not open `library.db`.

PARITY-GAP library.preview: Qt drag-compare as a separate top-level tool, animated playback past the first frame, and semantic similarity launched from the preview window are absent. Difference mode remains on the existing preview window only.
