# library.scan

Directory walk, row selection, path tag suggestions, and `scan.save_metadata` when a database session is attached. A missing session returns an error (`success: false`, `database_available: false`). It does not queue a fake write. The selected path can request preview describe and frame.

PARITY-GAP library.scan: Qt gallery cards, lazy pagination, directory import into series listings, and context-menu file actions are absent.
