# library.search

Filename, group, tag, and format filters search `library.list_images`. A selected row opens `library_preview.describe` and `library_preview.frame`. Previous/next walk the result list.

PARITY-GAP library.search: semantic "find similar", refresh-groups/tags buttons, add-all/remove-all format trays, and the Qt multi-window preview shell are absent. Preview here is the describe+frame payload, not a popped Qt viewer.
