The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Fixed

- Sampler validates the complete output plan against every selected source before writing, including native path aliases and duplicate destinations.
- Library registry loading keeps the HostClient receiver, and wallpaper graph nodes keep unique IDs after removals.
- Clipboard test doubles preserve the readonly browser API type during frontend checking.

Cloud Sync uses the remote's own temporary links where it has them; otherwise it goes through a transit bucket that is emptied after outputs are copied to the remote. Inputs are content-addressed and uploaded once.
  - **Workers:** a worker's manifest holds only presigned URLs, never credentials.
  - **Live events:** the worker re-uploads `events.jsonl` through one presigned PUT, and the daemon reads only the new bytes from its last offset.
  - **Retention:** planning covers staged inputs, LRU model caches under a storage budget, and outputs.
  - **Engine admission:** now uses `CloudSettings` limits on concurrent jobs, GPU instances and reserved spend. Only admitted jobs count toward reserved spend, so queued jobs can't block each other.
- Cloud Jobs safeguards (#830–#832), Qt-free:
  - **Settings:** `settings.py` holds one `CloudSettings` for caps, warning thresholds, admission limits, retries, regions, packing and retention.
  - **Risk rules:** `risk/` ships the rules as YAML (`rules.yaml`). Each rule targets form fields to recolour, lists fields to grey out, and has a ⚠ message filled from the job. User edits are stored in `cloud_jobs.db`, and every rule can be edited. Disabling a capability rule leaves a warning on each job it would have blocked, and that warning must be acknowledged.
  - **Cost model:** `cost/` has a layered price catalogue (user, then live, then curated). The curated seed ships empty instead of with unverified prices. Also: admission limits, the 80% budget alert, and estimate-vs-actual drift flags.
  - **Preflight:** `preflight/` runs a fixed-order pipeline: validate, data class, ComfyUI widget secret scan (strip or keep each hit; logs get a redacted copy), weight cloud-classes, quota probe, cost, then risk. - Wallpaper tab: dragging a thumbnail on Wayland wedged the whole app — every click stopped registering while the event loop kept running (not frozen). The gallery custom drag (`VirtualGalleryView`, `DraggableLabel`) was built on `QWidget.grabMouse()`, which on Wayland is a silent no-op for non-popup widgets ("This plugin supports grabbing the mouse only for popup windows"); the half-started drag left the widget as `mouseGrabber()` so every mouse event routed to it and never got released. Replaced the whole `grabMouse` + floating-preview mechanism with a native `QDrag` carrying the file URLs — the compositor owns the DnD grab, so it works on X11 and Wayland. Also fixed a stale `from .manager import MonitorDropView` in `MonitorDropView.dragEnterEvent` (no such module after a reorg) that raised `ModuleNotFoundError` on every drag-enter and silently rejected the drop, and a leftover `QListView` press state after `QDrag.exec()` that started a stray marquee on the next click (`gui/src/components/virtual_gallery/virtual_gallery_view.py`, `gui/src/components/labels/draggable_label.py`, `gui/src/components/views/display/_drag_drop.py`).
- Wallpaper tab: a stale application-wide event filter (`SystemDisplaySubTab` installs itself via `app.installEventFilter` but nothing ever removed it) routed every event through a dead C++ wrapper after teardown, raising `RuntimeError` per event and making the app unclickable. `eventFilter` now self-evicts on any `RuntimeError`, and `closeEvent` / the `destroyed` signal remove it on teardown (`gui/src/tabs/core/wallpaper_tab/common/wallpaper_common_base/_event_filter.py`, `_widget_ui_lifecycle.py`, `system_display_subtab/_ui_builder.py`).
- BiRefNet batch mask generation OOM'd on ≤12 GB GPUs for ~15+ frame sequences (`Tried to allocate ~3.75 GiB`), falling back to a slow per-frame loop. `_compute_batch_size()` underestimated Swin-L activation memory (32× raw tensor). Fixed with fp16 `autocast` on the forward pass (mask thresholded at 0.5, so fp16 is immaterial), `torch.inference_mode()`, per-chunk `empty_cache()`, a realistic 48× estimate with a hard cap of 2 on ≤12 GiB cards, and a live-OOM halve-and-retry. It ran twice: from `_startup_prefs` when the pref is on at launch, and again from `closeEvent`, whose `_tray_icon is None or not _tray_icon.isVisible()` guard re-fired on the transient not-yet-visible window right after `.show()` on Wayland/Plasma. `_setup_tray_icon()` is now idempotent (re-shows the existing icon and returns); `closeEvent` only creates when there is no icon yet (`gui/src/windows/main/_tray.py`, `_lifecycle.py`).
