# Cel-Shaded-Generator documentation

These pages are part of the Image-Toolkit documentation.

Cel-Shaded-Generator is an offline-first anime drawing tutor and cel-shaded art
tool in pre-alpha development. Start with:

- [Roadmap](../moon/roadmaps/cel.md) — product sequence and honest feature status
- [Architecture](cel-architecture.md) — current and target system boundaries
- [Development](cel-development.md) — accurate setup and commands
- [Testing](cel-testing.md) and [benchmarks](cel-benchmarks.md)
- [Portable project format](cel-project-format.md)
- [Character style-bible format](cel-style-bible-format.md)
- [Local model packages](cel-model-packages.md)
- [Changelog](../moon/cel-changelog.md)

The first user-facing milestone is a Krita plugin teaching anime head-and-face
construction. The current Qt executable is a solver demonstration shell.
