Manga Lineart Colorization & Palette Transfer

STAGE 01

Screentone-Aware Scribble Hints

Distinguishes fine ink lineart from dot screentones and crosshatching, allowing rapid color fills via sparse user color scribbles without bleeding across line boundaries.

STAGE 02

Reference-Palette Color Transfer

Extracts dominant color palettes from character reference art and maps them to target lineart regions using L-channel luminance matching and optimal transport color mapping.

STAGE 03

Temporal Graph-Cut Refinement

Propagates colorized keyframes across animation sequences using optical flow vectors and Graph-Cut energy minimization, eliminating frame-to-frame color flickering.

Layer Canvas & Process-Isolated Execution Boundary

Multi-Layer Document Model

Supports independent Lineart, Flat Color, Cel-Shadow, Highlight, and Screentone layers. Projects are saved in a portable offline .csg format containing raw raster assets and non-destructive mesh deformation parameters.

  • • Non-destructive vector lineart & raster layers
  • • Portable JSON project manifest format
  • • Local filesystem cache with zero cloud dependencies

Crash-Contained Native Compute

Heavy numerical jobs cross a serializable JobRequest boundary. Isolated worker processes run solver routines with process-local locks, adaptive timeouts, and crash recovery — ensuring the Qt/Krita UI never freezes.

  • • Persistent restartable worker process for ARAP dragging
  • • Spawned batch processes for temporal color propagation
  • • Process-local NATIVE_COMPUTE_LOCK defense-in-depth
