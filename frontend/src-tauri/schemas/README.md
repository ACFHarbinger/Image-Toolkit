Pinned copy of the Tauri capability schema generated by `tauri-build`
(`gen/schemas/desktop-schema.json`, which is gitignored). The security
check `middleware/validation/check_tauri_security.py` validates every
`capabilities/*.json` against this file, so capability syntax can never
drift from the tauri version we ship. Refresh it in the same PR that
bumps the tauri version:

    cd frontend/src-tauri && cargo check && cp gen/schemas/desktop-schema.json schemas/
