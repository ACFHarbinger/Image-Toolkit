# Cel-Shaded-Generator Qt Client

Experimental PySide6 demonstration client for the standalone
`cel_shaded_generator` engine. It exercises the imported colorization,
animation, and mesh-deformation prototypes; it is not the planned Krita
learning alpha.

From the repository root:

```bash
uv sync --all-packages --all-extras --dev
uv run --package cel-shaded-generator-gui python gui/launch.py
```
