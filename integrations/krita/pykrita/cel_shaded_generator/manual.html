Cel-Shaded Learning Tutor

An offline anime head-construction lesson, deterministic review, and private progress tutor.

The packaged curriculum currently contains fully authored front-construction and head-orientation lessons. Later lessons are added only when their explanations, drills, common mistakes, and completion criteria are complete.

Progress

The Project Progress section is part of the existing tutor docker. Raw normalized measurements are shown by default and can be hidden without deleting them. Refresh reads the bound portable project through the local engine.

Learning-progress retention starts enabled. “Disable & Clear Project Progress” asks whether to permanently erase the project history or cancel and keep it. “Enable Project Progress” turns future retention back on. Artwork history and global statistics are separate settings.

Advice feedback

After a saved review, choose Helpful, Unhelpful, Incorrect, or Not Applicable and optionally add a note. You may revise the rating or note. “Keep advice-feedback edit history” controls whether old revisions remain in the portable project and defaults off. The note-length setting defaults to 2,000 characters. Save Feedback Settings applies both choices to the current project.
